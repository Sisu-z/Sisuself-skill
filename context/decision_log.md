- 状态：**已决定，短期有效。**
- 锁定期：2026-09-30 至 2026-10-15，之后复盘。
- 决策：
  1. **Agent / AI 软件工程为短期主攻。**
  2. **智能车为第二项目保温**，只推进最近闭环，不主动扩张 ROS2/SLAM/VLA 等新坑。
  3. **传统数据结构算法继续**，先收尾核心章节，之后每周少量保温；不作为当前主战场。
  4. **深势追光者计划参加/准备**，但把它视为 Agent 工程能力的实战验收和潜在招聘出口，而非长期身份承诺。
  5. 10月15日前不主动新增第三条技术主线。
- 依据：
  - 当前最大现实短板是缺少完整软件工程/AI系统项目经验和可验证技术成果。
  - Agent 反馈周期短，能快速补 Git/API/DB/状态管理/测试/Eval/Debug 等软件工程能力。
  - 智能车提供物理系统/嵌入式/控制经验，且已有长期项目和后续资源，因此不应放弃，但短期无硬截止。
  - DSA 迁移性高且技术折旧慢，应持续，但边际收益低于当前项目闭环。
  - 用户明确表示 Agent 和智能车都不想放弃，并认可“主攻+保温”比等权并行更现实。
- 明确不是：
  - 不代表 Agent 是长期终局。
  - 不代表未来一定走具身/机器人。
  - 不代表深势是最佳或唯一实习。
  - 不代表暂停模型/科研意味着否定其长期价值。
- 允许提前重开的硬证据：
  1. 明确更高质量且冲突的现实机会；
  2. 当前 Agent 工程训练无法形成可复用能力/成果的实证；
  3. 深势条件彻底不可行且现有项目也无独立价值；
  4. 用户明确要求解除锁定并接受重新规划成本。
- 不构成提前重开的证据：
  - 单个博主或学长的新观点；
  - 某个行业薪酬案例；
  - “担心以后没用”的一般性预测；
  - 临时对另一个方向产生兴趣。
- 复查：2026-10-16 起，根据实际项目成果、比赛结果、智能车进展与新现实机会重新判断。
