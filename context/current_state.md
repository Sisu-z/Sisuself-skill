# Dynamic State · 当前状态

复查日是本仓库的维护建议；不是已安排的提醒。条目来源见 [sources](sources.md)。

## 阶段与当前主线

- [自述] 大二上，剩余约三年本科时间；正在从广泛了解转向能展示、能解释的实际产出。
- [当前短期节奏｜已决定] **2026-10-15 前：Agent / AI 软件工程为主攻，智能车为第二项目保温，传统数据结构算法为底座维护。**
- [主攻目的] Agent 不是长期身份承诺，而是当前用于补齐软件工程、AI 系统、Git/API/DB/状态管理/测试/Eval/Debug 等能力的快速入口，并用于参加深势追光者计划这类真实任务筛选。
- [智能车定位] 不放弃。当前只推进最近闭环（电机、编码器测速、PID、转向等），不在 10 月中旬前主动叠加 ROS2/SLAM/VLA/复杂视觉等新坑。
- [DSA 定位] Hello Algo 剩余核心章节继续收尾；之后长期保温，每周少量题目，不作为当前主战场。
- [深势定位] 参加/准备，但不把它当长期职业战略；比赛作为 Agent 工程能力的真实验收场。官方规则称首期后计划常态化滚动，且不同岗位专业能力会被考察。是否支持远程/具体到岗条件仍待核验。
- [暂停新增] 在 2026-10-15 前，不主动新增第三条技术主线（如 CUDA/Infra、基础模型训练、语音、纯科研复现等）；相关新观点进入观察队列，原则上不打断当前节奏。

## 当前短期战略锁

**锁定期：2026-09-30 ～ 2026-10-15。**

锁定期间默认不重开“Agent vs 具身 vs 模型科研”总路线争论。允许改变战术，不允许因单个视频、案例、薪酬故事或行业观点重置全部安排。

### 可提前重开的硬触发器

1. 出现明确、更高质量且时间冲突的现实机会（如强组明确接收并给真实课题/导师，或明显更优的核心团队 offer）。
2. 深势官方条件确认完全不可行，且当前 Agent 工程项目本身也无法形成可复用成果。
3. 当前项目出现明确事实表明训练目标与实际能力提升严重错位，而不是仅仅“担心未来没用”。
4. 用户明确要求提前解除战略锁并接受重评成本。

除此之外，新观点先问：**它具体击穿了当前计划的哪个前提？** 若说不清，不改主线。

## 当前项目与探索

- **Agent / AI 软件工程**：短期主攻。优先通过成熟项目建立工程直觉，再做二次开发；不要求一开始从零造大系统。
- **智能车自主泊车**：[smart-car-parking](https://github.com/Sisu-z/smart-car-parking)。作为长期第二项目，不放弃，但当前降为保温。
- **科学任务工作台**：[agentic-science-lab](https://github.com/Sisu-z/agentic-science-lab)。可作为现有尝试/比赛材料，但不要求国庆围绕它重新造一个庞大“科研 Agent 平台”。
- **科研、模型算法、Infra 等**：作为未来可能下沉方向观察；当前不主动开新主线。

## 关键未决问题

1. 深势比赛专用科研 Agent 全栈岗位是否支持远程/学期内在校投入？最低每周天数和持续时间如何？
2. Agent 工程短期训练后，是否形成可独立解释的工程成果与真实外部反馈？
3. 智能车完成当前闭环后，项目组真车资源能否转化成真实代码/数据/指导任务？
4. 2026-10-15 后，Agent 与智能车的长期比重如何调整？届时基于实际成果和现实机会复盘，而不是基于单个观点。
5. 读研、城市、强组、模型/具身/AI4S 等长期选择仍未最终决定。

## 最近认知变化

- 明确认识到近期最大问题不是“没找到完美赛道”，而是路线摇摆导致技术能力与项目资产增长近乎停滞。
- 当前更认同：**技术能力高频积累，市场/行业判断低频校准；战略低频，战术高频。**
- Agent 与智能车都保留，但不再等权并行：短期 Agent 主攻、智能车保温。
- 传统数据结构算法继续，但降为底座维护，不再与项目主线争夺主要时间。
